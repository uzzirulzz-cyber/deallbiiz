- **Key decisions**:
  - WS socket stored in zustand (non-persisted) and wired up once at the page level so every component can `emit('view', id)` without prop-drilling.
  - Only `savedIds` + `chatHistory` persist to localStorage; everything else (filters, live state, panel flags) is ephemeral.
  - React Query dedupes the listings list query across `ListingsGrid` and the page-level count query via shared `["listings", {…}]` key (the count query adds `count: true` to avoid collision but they hit the same endpoint).
  - Optimistic updates for save/unsave with rollback on error; `queryClient.invalidateQueries({queryKey:['saved']})` after every save/unsave so the Saved drawer never goes stale.
  - All images use plain `<img>` (the repo's eslint config disables `@next/next/no-img-element`).
  - Snap-a-Listing's "try a sample" uses a canvas-drawn business card (Acme SaaS Corp with $620K ARR, $1.8M asking, 92% margins, 4yr, +42% YoY chart) — the VLM reads it at 98% confidence, unlike the old broken base64 PNG approach.
  - Sticky footer via `min-h-screen flex flex-col` wrapper + `mt-auto` on the footer.
  - Mobile: hamburger Sheet replaces the desktop action bar; floating orange Sparkles FAB provides one-tap access to AI Valuation.
